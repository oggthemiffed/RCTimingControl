# Archived plans

These are historical plans, kept for reference. They are not current design: see `docs/architecture.md`, `docs/PROJECT.md` and `docs/REQUIREMENTS.md` for how RCTimingControl works today.

- `v1-planning/` holds the original ten-phase roadmap, research, phase plans and UAT records. Some of what they describe has since been removed by the local-only plan (#8), including the racer portal, the forwarder and gRPC, and the Docker deployment. The Docker trial environment phase (10) is left out, since it described image publishing that the installers replaced (#23, #24).
- `2026-08-0*-feat-offline-race-day-resilience*.md` are the plans for the separate offline race-day app, retired in #21.
